# Civilization Rebuilt｜文明重建

**從自然材料出發，透過觀察、試驗與推理，逐步重建文明。**

這是一款開發中的第一人稱文明模擬遊戲。玩家不靠點選配方解鎖科技，而是在材料、環境與自身能力的限制下找到可行方法，再讓一次成功成為能重複運作的能力。

**In Development · Started May 2026 · Windows PC 開發目標**  
**Unity 6 · C# · Universal Render Pipeline（URP）· Blender**

本庫展示研究、設計取捨與精選開發紀錄。圖片將隨後續成果補充；目前先以文字呈現。

## 這不只是一款收集材料的遊戲

拿到石頭，不等於已經擁有工具；找到能停留的位置，也不等於已經建立可靠的生活。玩家需要分辨眼前條件，決定去哪裡、搬什麼、怎麼安排，再從結果修正自己的理解。

例如，登高可能提供方向資訊，卻也花掉準備時間；讓材料接觸到需要的位置，與只把它堆在附近，是不同的事情。設計希望這些差異能被觀察、比較，而不是藏在物品名稱或任務勾選後面。

長期方向由生存延伸到工具、製造、知識保存與文明組織。**目前先製作自然環境、直接材料操作與基本生存，完整文明發展仍是後續目標。**

## 研究與設計文章

想先了解遊戲，從「核心理念」與「開場與首夜」開始；想看研究如何變成設計，可讀世界、冷環境、材料與季節；想看開發取捨，可讀直接互動、失敗迭代與旅程保存。

| 文章 | 具體內容 |
|---|---|
| [核心理念：知道，不等於做得到](design/CORE_PHILOSOPHY.md) | 以支架的設計情境，區分配方、條件、偶然成功與可靠能力。 |
| [世界設計：先理解地勢，再放湖泊](research/WORLD_DESIGN.md) | 比較景點串接、平均分布與連續地理；展開出生坡、低脊、谷地和局部湖岸的取捨。 |

研究文章在引用處交代來源能支持什麼；方案比較與設計推論另行說明。文中的待驗證情境不是已執行測試，也不把遊戲近似寫成普遍適用的自然定律。

## 專案分工與公開範圍

需求、方向與設計取捨由 KeeCharlotte 決定，AI 參與研究整理、程式、資產製作工具與文件工作。人工操作回饋與自動檢查各自記錄，不把 AI 的執行結果當成玩家已親自驗收。

公開版不提供完整遊戲、原始碼、模型與貼圖原檔、完整參數表、資源座標、保存格式或原始工程紀錄。這裡保留能解釋問題與取捨的內容，不是私人文件鏡像，也沒有額外的測試或建置環境。
