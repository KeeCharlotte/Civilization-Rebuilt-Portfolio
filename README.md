# Civilization Rebuilt｜文明重建

**從自然材料出發，透過觀察、試驗與推理，逐步重建文明。**

這是一款開發中的第一人稱文明模擬遊戲。重點不是點選配方解鎖科技，而是在材料、環境與自身能力的限制下，親自找到可行的方法，讓一次成功逐漸成為能重複運作的能力。

**In Development · Started May 2026 · Windows PC 開發目標**  
**Unity 6 · C# · Universal Render Pipeline（URP）· Blender**

本庫公開研究、設計取捨與精選開發紀錄，不提供完整遊戲、原始碼或美術資產原檔。

## 遊戲想讓人經歷什麼？

一塊石頭不會因為被選中就變成工具，一堆材料也不會因為放在一起就自動成為庇護所。玩家需要觀察、嘗試、承受結果，再調整做法。

長期方向是由生存走向工具、製造與文明組織；目前開發先聚焦自然環境、直接材料操作與基本生存。**後面的文明發展是目標，不是已完成的內容。**

## 現在做到哪裡？

截至 **2026-09-19** 的公開整理。下表區分已有實作與設計方向，不以工程檢查取代真人操作或正式發行驗收。

| 範圍 | 目前進度 |
|---|---|
| 第一人稱探索 | 已有移動、視角與姿態基礎；整體體驗仍需持續調整。 |
| 自然材料互動 | 已有石頭、木材與鬆散乾纖維的有限拿取、搬運、放置子集；完整雙手建造與加工仍未完成。 |
| 環境與生存 | 已有冷環境及水、食物、休息的有限流程；模型仍待校準，真人體驗尚未完整驗收。 |
| 世界與地形 | 已有地形與世界管理子集；完整溫帶草原、湖岸及季節生態仍在設計與製作。 |
| 旅程保存 | 已有本機保存與接續子集；完整使用情境仍待驗收，Steam 與雲端功能延後。 |
| 自然美術 | 已有第一方自然資產與早春樣本；不等於完整場景或最終美術。 |
| 工具、製造與文明發展 | 長期設計方向，尚未構成完整可玩內容。 |

Unity 是目前主遊戲的開發方向，遷移與完整驗收仍在進行。舊瀏覽器版本只作行為參考，不與 Unity 成果合併計算。
